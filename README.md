|---|---|
| 绑定章节 | ch8 游戏实现 / ch20 批量换皮生产（模板线） |
| 技术栈 | TypeScript + React 19 + Tailwind 4 + Vite |
| 测试 | vitest（无 Key 无网全绿） |
| 状态 | 骨架（2026-11-18 建仓；核心玩法随 ch8 章节灌入） |

npm install --registry=https://registry.npmmirror.com
