# harness-snake 行车记录仪——设计文档

> 2026-11-18 人裁收口（brainstorming 产出）。书《Harness 工程：Codex 智能游戏开发入门》ch8 配套仓（ch20 模板线载体，模板库本批不建）。

## 意图与为什么

把 harness-snake 从骨架写成**完整可玩**的贪吃蛇，突出点只有一个：**行车记录仪**——整局游戏全程 tick 级状态捕获，死亡后逐帧回放看死因，碰撞断言直接**从捕获数据写出**。书 ch8 章钩子原文：「给游戏装上行车记录仪之后，断言不再靠猜——状态捕获是本书后面存档、回放、修 bug 的共同源头」；snake 是这个母题的第一块实验田。换皮参数化是 ch8 第二交付物，做基础件（配置文件+一款示例皮肤+切换 UI），不抢突出点。

## 目标

- 完整经典贪吃蛇：20×20 网格（骨架常量已有）、方向键/WASD+触屏滑动、食物随机生成、吃到长身+加分、**三分支碰撞**（撞墙/咬自身判负，吃食物生长）——书 ch8 核心教学点
- 行车记录仪：每 tick 捕获一帧状态（蛇身/朝向/食物/分数/事件类型），整局录成一条紧凑记录；死亡面板给「回放案发经过」逐帧播放器（步进/暂停/倍速）
- 断言从捕获数据写：捕获器为纯函数，测试工作流=离线跑模拟局→捕获→对捕获序列写三分支断言（书「按捕获数据写断言」原题）
- 最近一局录像落 localStorage，成绩册最新条目可「回看录像」——成绩册不止是数字，能看案发经过（差异化点）
- 换皮参数化：换皮配置文件驱动视觉（配色/形状）+规则参数（初速/加速曲线），内置默认皮肤+1 款示例皮肤+切换 UI；禁止硬编码（仓铁律）
- 本地成绩册：历史分数/个人最佳，**读侧守卫净化前置**（2048 终审两轮命中畸形数据白屏，本仓第一天就带）

## 非目标 / 反目标

- ch20 规约模板库+批量生产脚本+降本核算表——**挂账 ch20 批**（照 2048 挂账 ch18 先例），本批只交付 ch8 的「换皮配置文件+一个换皮实例」
- 无后端、无排行榜、无上报；无广告/打包（不绑本仓章节）

## 关键设计裁定（builder check 前我方裁定，用户可否决）

1. **记录格式=增量快照序列，非输入流重放**：与 2048 的「种子+走子日志重放」刻意区分——行车记录仪拍的是**状态本身**（每 tick 蛇身增量+食物+分数+事件），回放=逐帧播快照，不重算不重放。理由：书教的是「状态捕获器实现与记录格式」，快照直白贴题；输入流确定性重放是 2048 的招，本仓不重复。增量编码（每 tick 只记新头格与尾格变化）控体积，千 tick 长局 ≈ 数 KB 级。
2. **捕获器是纯函数**：recorder 消费每次 tick 的结果吐捕获帧；测试可离线跑模拟局产出真实捕获序列再断言。UI 渲染层不参与捕获——逻辑层自带记录仪。
3. **穿墙不进默认规则**：经典撞墙制；穿墙仅作为换皮规则参数的候选示例值存在，不默认开。
4. **录像只存最近一局**：localStorage 体积与教学复杂度的平衡点；成绩册分数全量存+最近局录像单独一键。
5. **速度=可注入定时器**：tick 间隔由换皮配置（初速/加速曲线）驱动，测试注入虚拟时钟——逻辑层不知道 setInterval 存在。

## 视觉方向（builder 落地）

「行车记录仪/仪表盘」风：黑底荧光绿 HUD、REC 红点闪烁、tick 码表、速度档位读数；死亡=「事故报告」卡（死因判定+回放按钮）。克制、不花哨——个性在「这一局被全程记录」的仪式感，不在装饰堆料。换皮示例皮肤做**观感反差大**的一款（掌机灰绿或纸面手绘方向），让「换配置=换游戏气质」一眼可见。

## 状态机与语义裁定（builder check 2026-11-18 收口）

以下为评审问出的语义空洞，按「教学最简」原则裁定，全部是本轮裁定（用户可否决）：

1. **书稿与仓的先后**：书稿正文未写，本仓是代码块 source of truth，书稿从实现产出；仓只受 chapter-plan 节要点约束（三分支碰撞/状态捕获器与记录格式/按捕获数据写断言/换皮配置文件）——无印刷稿常量需要服从。
2. **反向输入**：同 tick 180° 掉头（右行按左）在输入层直接忽略，不进逻辑层——「咬自身」分支由真实转弯失误触发，不由反向键触发；单缓冲（每 tick 取最后一个有效键），不做输入队列。
3. **暂停/恢复/终局是捕获事件**：记录格式=生命周期事件（开局/暂停/恢复/终局含死因）+tick 帧（仅运行中产生）；回放时间轴在暂停处显示标记，不重复帧。（仓 CLAUDE.md「状态捕获（运行/暂停/结束）」为权威表述。）
4. **成绩册按皮肤分段**：规则参数（初速/加速）随皮肤配置，跨皮肤比分数是苹果比橘子——每皮肤独立最佳与历史；录像记录内嵌 skin id，回放按录制时的皮肤忠实渲染（否则「案发经过」失真）。
5. **满板=通关终态**：蛇身占满 400 格为第四终态「通关」（事故报告变通关报告，成绩正常落册）；状态机四分支穷尽，边界测试显式覆盖。实战几乎不可达，但机器必须会判。
6. **计分**：每食物固定 +10（配置常量，换皮可覆盖），不随速度档缩放——分数语义保持最简，与速度解耦。
